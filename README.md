HR Data Management & Reporting Project
📌 Project Overview

This project demonstrates the practical application of MS Excel in HR Operations by managing and reporting employee-style HR data using simulated datasets.

The focus is on maintaining accurate HR records, creating structured trackers, and generating clear HR reports while ensuring data consistency and confidentiality.

🎯 Objectives

Design structured employee master datasets

Track attendance and leave records

Create Excel-based HR trackers

Generate monthly HR reports

Maintain data accuracy and confidentiality

🗂️ Project Contents

Employee Master Data – Basic demographic and employment details

Attendance Tracker – Monthly attendance records

Leave Management Tracker – Leave availed and balance tracking

HR Project Report – Documentation explaining methodology and outcomes

🛠️ Tools Used

MS Excel – Data management, formulas, reporting

MS Word – Project documentation

📊 Datasets Used

All datasets used in this project are simulated (dummy data) and created solely for academic and learning purposes.
